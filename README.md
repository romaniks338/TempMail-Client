# TempMail-Client

Simple C++ client for temporary email using tempmailportal.com API

---

## Features

- Generate temporary email address
- Get access token
- Check incoming messages
- Clean console output

---

## Installation

```bash
git clone https://github.com/romaniks338/TempMail-Client.git
cd TempMail-Client
g++ main.cpp -o tempmail
./tempmail
